# Учебный проект    

Проект интернет-магазина, реализующий базовые сущности «Товар» и «Категория» с автоматическим подсчётом общего числа категорий и товаров. Данные загружаются из JSON-файла. Код покрыт модульными тестами.

## Описание
Проект демонстрирует:
- Создание классов `Product` и `Category` с заданными атрибутами.
- Автоматическое ведение счётчиков количества категорий и товаров (атрибуты класса).
- Чтение данных из JSON-файла

## Реализованный функционал

### Классы товаров
- **`BaseProduct`** — абстрактный базовый класс для всех продуктов. Определяет общие атрибуты (`name`, `description`, `quantity`), абстрактное свойство `price`, а также магические методы `__str__` и `__add__`.
  - В конструкторе проверяется, что количество не равно нулю, иначе выбрасывается `ValueError` с сообщением «Товар с нулевым количеством не может быть добавлен».
- **`Product`** — базовый класс товара, наследующий `BaseProduct` и миксин `ProductInitMixin`. Реализует приватное свойство `price` с геттером и сеттером.
  - Сеттер цены проверяет, чтобы цена была положительной. При попытке установить цену ≤ 0 выводится сообщение: «Цена не должна быть нулевая или отрицательная».
  - При понижении цены запрашивается подтверждение пользователя через `input` (y/n). При отказе выводится «Действие отменено».
  - Реализован класс-метод `new_product(cls, data: dict)`, создающий объект `Product` из словаря.
  - Магический метод `__str__` возвращает строку: «Название, X руб. Остаток: X шт.».
  - Магический метод `__add__` позволяет складывать два продукта одинакового типа. Возвращает сумму полных стоимостей (`цена × количество`). При попытке сложить товары разных типов возбуждается `TypeError`.
- **`Smartphone`** — наследник `Product`. Добавлены атрибуты: `efficiency`, `model`, `memory`, `color`.
- **`LawnGrass`** — наследник `Product`. Добавлены атрибуты: `country`, `germination_period`, `color`.

### Миксины
- **`ProductInitMixin`** — при создании любого продукта (или его наследника) печатает в консоль строку с именем класса и переданными параметрами.

### Исключения
- **`ZeroQuantityProductError`** — пользовательское исключение, которое выбрасывается при попытке добавить в категорию или заказ товар с нулевым количеством. Сообщение по умолчанию: «Товар с нулевым количеством не может быть добавлен».

### Категории и коллекции
- **`AbstractProductCollection`** — абстрактный класс для объектов, содержащих продукты. Определяет свойства `products`, `total_quantity`, `total_cost`.
- **`Category`** — наследник `AbstractProductCollection`. Содержит список товаров (приватный атрибут `__products`), название и описание.
  - Счётчики `total_categories` и `total_products` (класс-атрибуты) автоматически обновляются при создании категории.
  - Метод `add_product(product)` добавляет продукт в категорию. Перед добавлением проверяет, что переданный объект является экземпляром `BaseProduct` (или его наследником), иначе выбрасывает `TypeError`. Если количество товара равно нулю, вызывает `ZeroQuantityProductError`.
  - При успешном добавлении выводится «Товар добавлен», при ошибке — сообщение исключения. В любом случае выводится «Обработка добавления товара завершена».
  - Геттер `products` возвращает копию списка товаров (безопасный доступ).
  - Свойства `total_quantity` (суммарное количество единиц товара) и `total_cost` (общая стоимость) вычисляются на основе всех товаров категории.
  - Метод `average_price()` возвращает среднюю цену товаров. Если товаров нет, возвращает 0 (обрабатывается `ZeroDivisionError`).
  - Реализован итератор `ProductIterator`, позволяющий перебирать товары категории в цикле `for`.
  - Магический метод `__str__` возвращает: «Название категории, количество продуктов: X шт.».
- **`ProductIterator`** — отдельный класс-итератор для перебора товаров категории.


### Заказы
- **`Order`** — наследник `AbstractProductCollection`. Содержит один товар и количество. Вычисляет итоговую стоимость.
  - В конструкторе проверяются типы и количество: если товар не является продуктом — `TypeError`; если количество товара равно нулю — `ZeroQuantityProductError`; если заказанное количество ≤ 0 — `ValueError`.
  - При успешном создании выводится «Товар добавлен», при ошибке — сообщение исключения. В любом случае выводится «Обработка добавления товара завершена».
  - Свойства `products`, `total_quantity`, `total_cost`.
  - Магический метод `__str__` выводит информацию о заказе: «Заказ: название, количество × цена = стоимость».

### Загрузка данных
- Функция `load_categories_from_json(file_path)` в `src/utils.py` читает JSON-файл и преобразует его в список объектов `Category` с вложенными товарами. Поддерживает структуру с ключами `name`, `description`, `products`.
- Демонстрация работы находится в `main.py`.

### Тестирование и качество кода
- **Набор тестов** (pytest) покрывает:
  - инициализацию `Product` и `Category`;
  - счётчики категорий и товаров;
  - работу `add_product` (включая проверку типа, нулевого количества и увеличение счётчика);
  - строковое представление `Product` и `Category`;
  - сложение продуктов одинакового типа и ошибку `TypeError` для разных типов;
  - сеттер цены (положительное значение, нулевое, отрицательное, понижение с подтверждением/отказом);
  - класс-метод `new_product`;
  - загрузку данных из реального JSON-файла;
  - миксин вывода параметров;
  - итерацию по товарам категории;
  - метод `average_price` (в том числе для пустой категории);
  - исключения `ZeroQuantityProductError`, `ValueError`, `TypeError`;
  - вывод сообщений при добавлении товара (успех/ошибка/завершение).
- **Линтер flake8** с конфигурацией в `.flake8`, исключающей виртуальное окружение и задающей длину строки 79 символов.
- **Отчёт о покрытии** генерируется с помощью `coverage.py`; публикуется на GitHub Pages (опционально).

## Требования

- Python 3.8+
- Зависимости: pytest, pytest-cov, flake8, coverage (см. `requirements.txt`)

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости.
4. Поместите файл products.json в папку data/ (уже есть).
5. Запустите программу: main.py

## Для генерации отчёта о покрытии:
coverage run --source=src --branch -m pytest tests/
coverage html
Отчёт появится в папке htmlcov/ (откройте index.html в браузере).
